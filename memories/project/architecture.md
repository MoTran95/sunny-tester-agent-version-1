# Kiến trúc tổng thể
Cập nhật: 2026-11-17 · Liên quan: [overview.md](overview.md)

_Chưa có kiến trúc — repo còn trống._

Khi bắt đầu viết code, ghi tại đây:
- Ngôn ngữ, framework, công cụ build/chạy/test (kèm lệnh).
- Cây thư mục chính và vai trò từng thư mục.
- Các module chức năng và quan hệ giữa chúng (mỗi module có thư mục riêng trong `memories/modules/`).
- Luồng dữ liệu / điểm tích hợp bên ngoài.
